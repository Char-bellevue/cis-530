Spring AI provides APIs for chat models, embedding models, image models,
audio models, and vector stores. In a Spring Boot project, developers can
inject an auto-configured ChatClient.Builder and use it to create prompts.
Spring AI allows the developer to focus on application design instead of
manually writing low-level HTTP calls to model providers.

Output parsers are useful when an application needs data in a reliable
structure instead of free-form text. For example, an application may need
a summary, a list of action items, and a list of important terms.
BeanOutputConverter can help map a model response into a Java class.
